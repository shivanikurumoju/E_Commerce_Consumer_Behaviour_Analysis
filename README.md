# E-Commerce Consumer Behaviour Analysis

## Project Overview

An end-to-end data analysis project focused on understanding customer purchasing behaviour in an e-commerce dataset. SQL was used for data analysis and extracting business insights, while Power BI was used to create an interactive dashboard for visualizing customer behaviour, purchasing patterns, and key performance indicators.

## Business Objective

The objective of this project is to analyze e-commerce customer behaviour and identify meaningful patterns related to purchases, customer activity, product preferences, and overall consumer behaviour.

## Tools & Technologies

- SQL
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Analysis
- Data Visualization

## Project Workflow

1. Imported and explored the e-commerce dataset.
2. Cleaned and prepared the data for analysis.
3. Used SQL to answer business-related questions and analyze consumer behaviour.
4. Created calculated measures and KPIs using DAX.
5. Designed an interactive Power BI dashboard.
6. Used visualizations to communicate key findings and patterns.

## SQL Analysis

SQL was used to perform:

- Data exploration
- Aggregations and calculations
- Customer behaviour analysis
- Purchase pattern analysis
- Product and category analysis
- Business-focused queries
- KPI calculations
